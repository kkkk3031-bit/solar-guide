# SolarCore — Residential Solar Power Engineering Guide

A premium, bilingual (Arabic-first + English) static guide to home solar power:
components, panel/inverter/battery comparisons, brand picks, system & AC sizing,
an animated "how it works" energy-flow tutorial, interactive engineering
calculators, installation/maintenance, and financial analysis.

Pure HTML5 + CSS3 + vanilla JS. Dark/light themes, RTL/LTR, SEO meta, no build step.
